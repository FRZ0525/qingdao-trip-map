# 杭州 → 青岛 自驾行程地图（4 天 3 晚）

在线查看：https://frz0525.github.io/qingdao-trip-map/

两人自驾杭州 → 青岛（住市南区 3 晚）的交互式行程地图，手机和电脑都能用。日期未定，按第1天–第4天排：

- **自驾**：第1天 7:00 出发，第4天早饭后返程。G25 长深 → S39 江宜 → G2 京沪 → G25 淮连 → G15 沈海，单程约 762 km、纯开车约 8 小时 46 分（OSRM 估算）。图上标出沿途服务区和充电信息：去程推荐 **宝应服务区**（约 354 km）充电，回程推荐 **平桥服务区**（离青岛约 371 km）；后半程补电备选日照 / 海青（去程）、小黄山 / 淹城（回程）。
- **青岛三天**：第1天晚上台东步行街；第2天栈桥 → 天主教堂 → 劈柴院 → 信号山 → 大学路 → 小鱼山 → 八大关 / 第二海水浴场 → 奥帆中心灯光秀 → 五四广场；第3天崂山（大河东换乘观光车 → 太清宫）→ 青岛啤酒博物馆 → 登州路啤酒街；第4天可选石老人海水浴场。每天一种颜色，景点按顺序编号，点击查看地址、开放时间、门票和交通。
- **购票 / 预约**：崂山（提前 7 天）、啤酒博物馆、信号山观景楼、天主教堂、小鱼山、浮山湾灯光秀，写的是相对参观日什么时候买，附来源链接。
- **贴士**：天气、停车、住、电车续航、吃、酒驾、证件、市内交通。
- 每个点都有「高德导航 / 高德查看 / 百度地图」按钮。

数据来源：路线由 OSRM / FOSSGIS 路由（OpenStreetMap 数据）预先计算后内置在页面中；坐标来自 OpenStreetMap（Nominatim / Overpass）；开放时间和购票规则来自景区官网、官方公告和新闻报道（2026 年），出行前请再次确认。底图：在线打开默认 OpenStreetMap，本地文件打开默认 Esri。页面为单个 HTML 文件，Leaflet 已内联。
